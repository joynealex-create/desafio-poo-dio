# ☕ Desafio POO - Bootcamp DIO

## 📖 Sobre o Projeto

Este projeto foi desenvolvido como parte do desafio de **Programação Orientada a Objetos (POO)** da **Digital Innovation One (DIO)**.

O objetivo é colocar em prática os principais conceitos da orientação a objetos em Java por meio da criação de um sistema que simula um **Bootcamp**, permitindo o cadastro de desenvolvedores, cursos e mentorias, além do acompanhamento da evolução dos participantes.

---

## 🚀 Conceitos Aplicados

Neste projeto foram utilizados os principais pilares da Programação Orientada a Objetos:

- ✅ Abstração
- ✅ Encapsulamento
- ✅ Herança
- ✅ Polimorfismo

Além de conceitos como:

- Classes e Objetos
- Métodos
- Coleções (Set)
- Relacionamentos entre classes
- Sobrescrita de métodos
- Organização em pacotes
